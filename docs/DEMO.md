# Suggested academic demo

1. Open Researcher Portal and create a trial (for example age 18–65, biomarker 70–140, diagnosis code 101).
2. Open Patient Wallet.
3. Click **Load demo hospital credential** and save it using a PIN.
4. Unlock it and select the trial.
5. Click **Check & prove locally**.
6. Show that the UI says clinical values stayed on the device.
7. Submit the proof.
8. Return to Researcher Portal and refresh matches; only an anonymous wallet/commitment appears.
9. Explain that production re-identification would occur only after explicit patient consent and a secure encrypted communication handshake.
